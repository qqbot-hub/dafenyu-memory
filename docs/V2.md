# v2.0.0 — 记忆星图 Atlas：改了什么，为什么这样改

> 基线：v1.0.0（fac8dd6）。v2 不改 v1 的核心承诺：零依赖主链路、owner/visibility 双重隔离、五路检索、被想起续命、夜巡自证数字。
> 本文档是 v2 的单一事实来源，写了什么、没写什么、哪里是近似，都写在这里。

## 1. 研究结论（2026-10-31 核查，快照会变动）

### 已核实、可引用
- 主流：mem0（Apache-2.0，事实层 + 融合检索 + 显式取代）、Letta（Apache-2.0，三级记忆 + 闲时整理）、Graphiti（Apache-2.0，时间图谱，事实用 valid/invalid 时间而不是删除）。
- DSH/QQ 社区：LivingMemory（AGPL，AstrBot 插件，2D/3D 图谱最成熟）、dafenyu-astrbot 的只读星海展示层（MIT，明确说曲线与线索检索是本地模拟）、Kagurazaka135/dsh-memory（轻量 Markdown/YAML，无语义）、SurfCore 记忆卡（会衰减的提示词卡 + 永不遗忘的全量卡，三端同卡）。
- 本项目 v1：MIT，零依赖，面板是力导向图。

### 只在视频/笔记里宣称，未拿到仓库链接前一律标未核实
- dsh-chain、3d-memory-sea、“个”的独立大脑、Prison 的多层架构（作者自述打磨完开源，截至核查未发布）、POTA_CHIPS 星图的具体实现路径、Companion-AI-Memory v1.4 与同名仓库的对应关系。
- 这些只能作为视觉与流程参考，不能作为可复用的开源实现引用，更不能原样复刻代码或文案。

### 许可红线（v2 严格执行）
- LivingMemory 与 memory-brain 均为 AGPL-3.0：**只借鉴思路、全部重写，绝不把它们的代码搬进 MIT 仓库**，也不把 AstrBot/AGPL 插件打包后仍称整个 MIT。
- mem0、Letta、Graphiti 是 Apache-2.0：借鉴思路可以，真正复用代码时要保留 Apache 声明。v2 目前没有直接复用它们的代码。
- 抖音视频的文案、画面文字、他人记忆原文一律不进仓库示例；测试用的是合成记忆。

## 2. v2 新增能力

### 后端
- `GET /atlas`：星图瘦载荷。节点只给短标签（≤18 字），完整原文点节点时才走 `GET /memory/:id` 取；聚合含按类型、按分类统计、30 天时间线、28 天热力近似、最常被想起榜。
- `GET /simulate-decay?days=30`：模拟衰减预览，纯计算，**绝不写库**。
- `GET /export` / `POST /import`：v2 导出格式（带 format/version 校验），换机器迁移用；导入拒绝非本格式，重复 id 跳过。
- 冲突取代：`POST /remember` 传 `supersedes: 旧 id` 时，旧记忆标记为 `superseded`，保留“以前是什么”，不再参与 active 召回。取代不是删除。
- 可选 embedding：`MEMORY_EMBED_URL` / `config.embed` 配 Ollama（默认 bge-m3）后，语义路才启用；不配或连不上时语义路为 0，不报错、不阻断记忆。`POST /recall` 传 `explain:true` 可看到五路分数明细，MCP 的 `mem_recall` 也透传了 explain。
- 修复：`lib/store.mjs` 里 `appendEpisode/appendDigest` 原来引用了不存在的文件变量与函数型数据目录，已改为按实际文件路径写。

### 面板（/panel 现在就是 v2，旧版在 /panel-legacy）
零依赖 Canvas，同一个过滤集合，五种投影共用状态（搜索、类型、时间、变淡/归档开关、模拟衰减滑块）：
1. **总览星海**：按核心/选中长期/普通/变淡分环，金色核心、青蓝选中、灰蓝普通、灰紫虚环变淡；亮度 = 留存度；拖拽平移、滚轮缩放、点节点看详情。
2. **时间与遗忘**：横轴创建时间、纵轴留存度；选中记忆画一条模拟衰减曲线（预览）。
3. **人格核心环**：中心钉住与元记忆，往外是选中长期、普通、最外圈变淡，故意不用乱飘的力导向。
4. **实体子图**：只画选中记忆/实体 1 跳内的邻居，关联才读得清。
5. **唤起热力**：近 28 天创建 + 上次被想起的近似活动 + 最常被想起榜。**必须注意：底层目前不记逐日召回日志，热力不是逐日召回历史，面板里已标明这一点。**

### 性能与诚实边界
- 星图默认截断 500 条、边 2000 条；星海只在放大或选中时画标签；发光用预渲染径向精灵，不用逐节点 shadowBlur。
- 节点数不会为了好看而虚构：没有的记忆不画，归档/被取代默认不进主视图，要手动打开开关才看得到。
- 模拟衰减、热力近似、LivingMemory/星海的“本地模拟”属性，都在界面与文档里标明，不冒充真实运行数据。
